# 不在同一局域网时，怎么用手机打开

## 一、先理解为什么不能「把网页传上去」

管理后台不是静态网页，它是一整套系统：

§§§
手机浏览器  →  管理后台页面  →  /api 接口  →  PostgreSQL 数据库
§§§

只把前端文件传到某个静态托管上，页面能打开但**数据全是空的**（接口连不上）。
所以「不在同一局域网」= 必须有**公网入口**，要么把整台机器暴露出去，要么把整套部署到公网服务器。

## 二、方案 A：内网穿透（最快，5 分钟）

把本机的 3100 端口映射成一个公网网址，手机直接开那个网址。

| 工具 | 免费额度 | 门槛 | 国内速度 |
|---|---|---|---|
| **Cloudflare 快速隧道** | 无限 | **不用注册**，一条命令 | 一般，时好时坏 |
| **cpolar** | 随机域名 1 条隧道 | 注册账号 | 好（国内节点） |
| **natapp** | 免费隧道 | 注册 + 实名 | 好 |
| **花生壳** | 1G 流量/月 | 注册 + 实名 | 好 |

### 先试这个：Cloudflare 快速隧道（不用注册）

§§§powershell
winget install --id Cloudflare.cloudflared -e
# 装完开一个新窗口，然后：
cloudflared tunnel --url http://localhost:3100
§§§

命令会打印一个 `https://xxxx-xxxx.trycloudflare.com` 网址，**手机直接打开就能用**。
这条隧道是临时的，关掉命令就失效，每次重启网址都会变。

> 注意：Cloudflare 在国内访问不稳定。如果手机打不开，换下面的 cpolar。

### 国内首选：cpolar

1. 去 https://www.cpolar.com 注册（邮箱即可）
2. 下载 Windows 客户端并安装
3. 在官网后台「验证」页面复制 authtoken，执行一次：`cpolar authtoken 你的token`
4. 起隧道：`cpolar http 3100`
5. 输出的 `https://xxxx.cpolar.cn` 就是手机能开的网址（免费版每次重启会变，付费可固定）

### 好在哪里

**管理后台不用改任何代码。** 它请求接口用的是相对路径 `/api`，
不管是 `localhost:3100`、穿透域名还是自己的域名，打开就能用。

### 要改的只有一处：小程序

§§§js
// apps/miniapp/config.js
const BASE_URL = 'https://xxxx.cpolar.cn/api';   // 换成穿透/域名地址
§§§

`ADMIN_URL` 和 `ASSET_URL` 都是从 `BASE_URL` 推导的，改这一行就够了。
改完在开发者工具里重新编译，或用「预览」扫码在真机上验证。

## 三、方案 B：部署到云服务器（正式运营走这条）

阿里云 / 腾讯云轻量应用服务器，学生机一年几十块，2 核 2G 就够。

大致流程（详见 `docs/06-部署与交付.md`）：

§§§bash
# 服务器上
apt install -y postgresql-16 postgresql-16-pgvector   # Linux 上装 pgvector 是一条命令，不用编译
pnpm install && pnpm build
pnpm build:admin        # 后端会托管它，整站一个端口
NODE_ENV=production node apps/server/dist/main.js
§§§

前面挂 nginx + HTTPS，或者直接让后端监听 80/443。

**优点**：网址固定、手机随时能开、可以给别人用。
**代价**：要买服务器、要维护。

## 四、方案 C：手机上其实用微信小程序更合适

你已经有小程序了。手机上装小程序比开网页体验好，而且商家工作台里能看订单、发货、审售后。

**但它解决不了「改商品」**：新增/编辑商品、上传图片、配置 AI，这些只在电脑端后台有。
所以小程序是「值班」用的，网页是「运营」用的，两者互补。

## 五、穿透 / 上线之前的安全清单（重要）

一旦暴露到公网，**全世界都能访问你的后台**。默认账号是公开写在所有文档里的，先做这三件事：

| 做什么 | 怎么做 | 为什么 |
|---|---|---|
| **改管理员密码** | `pnpm --filter @campus/server admin:password 你的新密码` | 默认 `admin123` 是公开的，穿透出去等于把后台送人 |
| **改 JWT_SECRET** | `.env` 里换成随机串：`node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"` | 占位密钥能被用来伪造登录 token |
| **确认生产开关** | `NODE_ENV=production` | 会自动关闭接口文档（避免暴露全部接口结构），并**拒绝用占位密钥启动** |

还有两点：

- 穿透网址是公开的，**别把网址发到群里**；cpolar 免费版域名随机，也算一层保护
- 上线前把演示数据清一遍：`pnpm --filter @campus/server data:clear-demo`（会先备份）

## 六、换地址后要同步改的地方（清单）

| 位置 | 改什么 |
|---|---|
| `apps/miniapp/config.js` | `BASE_URL` 换成公网地址（**必改**，否则小程序还连 localhost） |
| 管理后台 | **不用改**，接口用相对路径 `/api` |
| 后端 `.env` | 一般不用改；如果前端域名和后端不同源，需要配 `CORS_ORIGINS` 白名单 |
| 微信小程序后台 | 上线要在「开发设置 → 服务器域名」里把新域名加进 request 合法域名 |
