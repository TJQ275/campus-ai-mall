# 不在同一局域网时，怎么让手机访问

## 零、先说清楚：局域网只是「开发阶段」的事

**产品真正跑起来是这样的：**

§§§
用户手机上的小程序  ──微信服务器──>  你的公网服务器（HTTPS 域名）
商家的浏览器        ──────────────>  你的公网服务器（HTTPS 域名）
§§§

**跟局域网没有任何关系。** 用户的手机在哪、连什么网络都无所谓。

那为什么现在必须同一局域网？因为你现在的「服务器」就是你这台电脑 ——
手机要访问它，只能通过局域网。**这一步只用于开发和调试**，不是产品形态。

### 微信的硬性要求（这点绕不过去）

想让陌生人正常用你的小程序，必须在小程序后台配置 **request 合法域名**，要求是：

| 要求 | 说明 |
|---|---|
| 必须 HTTPS | `http://` 一律不行 |
| 必须是**已备案**的域名 | 国内服务器要 ICP 备案（1-2 周），这也是为什么很多人卡在这一步 |
| 不能用 IP | `http://192.168.1.100:3100` 这种**永远**配不进去 |
| 不能带端口 | 只能是 443 |

**结论：没有「公网 + HTTPS + 备案域名」这套东西，小程序就发布不了。**
在那之前，只能靠「开发调试」开关绕过校验，给体验成员临时用。

| 路线 | 要什么 | 多久 | 适合 |
|---|---|---|---|
| **A. 内网穿透** | 一条命令，**不用注册** | 1 分钟 | 演示、答辩、给体验成员看 ✅ **已实测可用** |
| **B. 云服务器 + 域名** | 服务器（学生机约 ¥100/年）+ 域名（约 ¥30/年）+ 备案 | 1–3 周 | 正式上线、能给别人用 |
| **C. 小程序体验版** | 先用 A 演示，正式版仍需 B | — | 手机上体验比开网页好 |
## 一、为什么不能「把网页传上去」

管理后台不是静态网页，它是一整套系统：

§§§
手机浏览器  →  管理后台页面  →  /api 接口  →  PostgreSQL 数据库
§§§

只把前端文件传到某个静态托管上，页面能打开但**数据全是空的**（接口连不上）。
所以「不在同一局域网」= 必须有**公网入口**：要么把整台机器临时暴露出去，要么把整套部署到公网服务器。

## 二、方案 A：内网穿透（已实测可用，1 分钟）

把本机的 3100 端口映射成一个公网网址，**手机在任何网络都能开** —— 流量、别家 WiFi 都行。
项目自带一键脚本，不用注册、不用实名、不用买域名：

§§§powershell
pnpm dev:server                       # 先确保后端在跑
pwsh -File scripts/tunnel.ps1 -Apply  # 起隧道 + 自动配好小程序

pwsh -File scripts/tunnel.ps1 -Status # 看状态（带自检）
pwsh -File scripts/tunnel.ps1 -Stop   # 关掉
§§§

跑完会打印一个 `https://xxxxxxxx.lhr.life`。**同一个地址同时能开两样东西**：

| 打开方式 | 地址 | 谁能用 |
|---|---|---|
| 浏览器（手机/电脑） | `https://xxx.lhr.life/` | 管理后台 |
| 小程序 | `https://xxx.lhr.life/api` | 买家端 / 商家端 |

### 实测结果（真跑过，不是估计）

| 检查项 | 结果 |
|---|---|
| `/api/health` 打到真后端 | ✅ `db=postgres tables=29 latency=24ms` |
| 管理后台首页 | ✅ HTTP 200，Vue 挂载点存在 |
| 静态资源（JS/CSS） | ✅ 正常加载，不会白屏 |
| 接口鉴权 | ✅ 未登录返回 401（符合预期） |
| **90 秒连续 15 次请求** | ✅ **14 次成功、1 次失败**（唯一失败是刚建好隧道后的第一次，客户端超时，属预热） |

### 脚本做了什么

1. 检查后端在不在（不在就直接告诉你 `pnpm dev:server`）
2. 提醒你改掉默认管理员密码（公开的 `admin123` 等于把后台送人）
3. 用 SSH 反向隧道把 3100 端口推上公网：
   §§§
   ssh -T -R 80:localhost:3100 nokey@localhost.run
   §§§
4. 从输出里抓出公网地址，**并自己请求一次 `/api/health` 验证真的通**
5. `-Apply` 时把地址写进 `apps/miniapp/config.js` 并设 `FORCE_ENV='prod'`

> `-T` 必须加：不给 TTY 时 localhost.run 才打印地址横幅。这个坑踩过。

### ⚠️ 为什么不用 Cloudflare 快速隧道（重要）

原本想用 Cloudflare（同样不用注册），但**在本机网络下连不上**。实测日志：

§§§
|  UDP Connectivity  region1.v2.argotunnel.com  FAIL   QUIC connection failed              |
|  TCP Connectivity  region1.v2.argotunnel.com  FAIL   HTTP/2 connection is blocked        |
|  ERROR: Allow outbound QUIC traffic on port 7844 or use HTTP2.                           |
|  SUMMARY: Environment has critical failures. cloudflared may not be able to establish... |
§§§

结论：**运营商封了 7844 端口**（UDP 和 TCP 都封），而这是 cloudflared 的专用端口。
表现很有迷惑性 —— 隧道会显示「建立成功」、也能拿到 `xxx.trycloudflare.com` 网址，
但一访问就是 **HTTP 530**。加 `--protocol http2` 也没用，TCP 7844 同样是封的。

**所以国内网络下不要指望 Cloudflare 免费隧道。**

### 顺便记一下：GitHub 也是不通的

（这是在排查 cloudflared 时发现的，以后装别的东西也会遇到）

| 源 | 实测速度 | 下完 52MB |
|---|---|---|
| GitHub 直连 | 超时（25 秒无响应） | 不可用 |
| ghproxy.net 镜像 | **20 KB/s** | 约 44 分钟 |

| 工具 | 免费额度 | 门槛 | 说明 |

| cpolar | 随机域名 1 条隧道 | 注册邮箱 | 国内节点，速度更好 |

### 管理后台不用改任何代码

它请求接口用的是**相对路径** `/api`，所以 `localhost:3100`、穿透域名、自己的域名 —— 
换哪个都能打开，一行都不用改。**要改的只有小程序那一处，`-Apply` 已经帮你改好了。**

### 小程序那边还要做一件事

微信开发者工具 → 详情 → 本地设置 → 勾选 **「不校验合法域名」**。

因为 `lhr.life` 没有 ICP 备案，**加不进**小程序后台的「服务器域名」白名单，
所以这条路的定位是：**演示、答辩、给体验成员看**，不是正式发布。
正式发布必须有备案域名，见下面方案 B。

### 临时地址的注意事项

- 隧道一关就失效，**重开会换一个新地址**（脚本会自动更新 `config.js`）
- 想还原成局域网联调：把 `config.js` 的 `FORCE_ENV` 改回空字符串 `''`
- 免费隧道不保证 SLA，重要演示前先 `-Status` 自检一下

## 三、方案 B：部署到云服务器（正式运营走这条）

阿里云 / 腾讯云轻量应用服务器，学生机一年几十块，2 核 2G 就够。

大致流程（详见 `docs/06-部署与交付.md`）：

§§§bash
# 服务器上
apt install -y postgresql-16 postgresql-16-pgvector   # Linux 上装 pgvector 是一条命令，不用编译
pnpm install && pnpm build
pnpm build:admin        # 后端会托管它，整站一个端口
NODE_ENV=production node apps/server/dist/main.js
§§§

前面挂 nginx + HTTPS，或者直接让后端监听 80/443。

**优点**：网址固定、手机随时能开、可以给别人用。
**代价**：要买服务器、要维护。

## 四、方案 C：手机上其实用微信小程序更合适

你已经有小程序了。手机上装小程序比开网页体验好，而且商家工作台里能看订单、发货、审售后。

**但它解决不了「改商品」**：新增/编辑商品、上传图片、配置 AI，这些只在电脑端后台有。
所以小程序是「值班」用的，网页是「运营」用的，两者互补。

## 五、穿透 / 上线之前的安全清单（重要）

一旦暴露到公网，**全世界都能访问你的后台**。默认账号是公开写在所有文档里的，先做这三件事：

| 做什么 | 怎么做 | 为什么 |
|---|---|---|
| **改管理员密码** | `pnpm --filter @campus/server admin:password 你的新密码` | 默认 `admin123` 是公开的，穿透出去等于把后台送人 |
| **改 JWT_SECRET** | `.env` 里换成随机串：`node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"` | 占位密钥能被用来伪造登录 token |
| **确认生产开关** | `NODE_ENV=production` | 会自动关闭接口文档（避免暴露全部接口结构），并**拒绝用占位密钥启动** |

还有两点：

- 穿透网址是公开的，**别把网址发到群里**；cpolar 免费版域名随机，也算一层保护
- 上线前把演示数据清一遍：`pnpm --filter @campus/server data:clear-demo`（会先备份）

## 六、换地址后要同步改的地方（清单）

| 位置 | 改什么 |
|---|---|
| `apps/miniapp/config.js` | 换成公网地址（**必改**）。跑 `pwsh -File scripts/tunnel.ps1 -Apply` 会自动改好 |
| 管理后台 | **不用改**，接口用相对路径 `/api` |
| 后端 `.env` | 一般不用改；如果前端域名和后端不同源，需要配 `CORS_ORIGINS` 白名单 |
| 微信小程序后台 | 上线要在「开发设置 → 服务器域名」里把新域名加进 request 合法域名 |
